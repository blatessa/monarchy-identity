# Quick reference: work laptop sign-in

| I want to... | Do this |
|---|---|
| Sign in | Username, **Enter**, password, **Enter** |
| Sign in as someone else | **Shift+Tab** to the username box, type the other name |
| Unlock the screen | Your company password |
| Change my password | Terminal (**Super+Enter**), run `passwd` |
| Password expired / must change | Web portal first, or try a **Ctrl+Alt+F3** text login |
| Work offline | Works if I signed in on this laptop before while connected |
| Check my laptop's setup | `monarchy-identity status` |
| Get a text screen | **Ctrl+Alt+F3** (back to graphical: **Ctrl+Alt+F1** or **F2**) |

**Red boxes** = sign-in didn't work (typo, Caps Lock, not allowed here, or locked).
**10 wrong tries in a row** = about 2 minutes of waiting.
**Tell IT:** username, time, what the screen showed, and the output of `monarchy-identity status`.
**Never share your password.**
