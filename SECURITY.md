# Security policy

Report vulnerabilities privately with GitHub's
[Report a vulnerability](https://github.com/blatessa/monarchy-identity/security/advisories/new), not a public issue.
Include the version, what you did, what you expected, and the impact. For example: getting past the login policy,
locking out local users or root, exposing enrollment credentials, getting an unvalidated value into the configuration
it writes, or an unprivileged user changing that configuration.

Fixes go into the latest release.
